My entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun — one original one-line joke about office life, judged pairwise by a comedy-club judge model.

## The joke

> I finally got promoted: my title gained the word 'senior' and my salary gained the word 'soon'.

## How it works

`main.py` (Python 3, standard library only, deterministic, no network) writes the single joke line to `/output/entry.txt`. The entry is one line, 95 characters — inside the competition gate of 1–200 UTF-8 characters.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Build notes

- Built fresh for this competition; the joke was written from scratch for this entry.
- The repository was created after the competition opened, as the competition requires.
- The punchline turns on the parallel "senior" / "soon": the title moves up, the pay stays promised.
